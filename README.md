# parking-web-client

> Operar check-in, check-out e mapa de vagas de estacionamento em interface web responsiva.

## Problema

Operar check-in, check-out e mapa de vagas de estacionamento em interface web responsiva.

## Solução

CRA com React, Redux Saga para fluxos assíncronos, Styled Components, máscaras de input e persistência de estado com Redux Persist.

## Stack

- React
- TypeScript
- Redux Saga
- Styled Components
